# Operación

Tareas para desplegar y mantener un entorno de Lumia Studio en AWS: despliegue, carga de contenido y accesos, y diagnóstico de problemas.

- [deployment.md](deployment.md): stacks, tres pasadas, comandos, riesgos e imagen del agente. Se lee para desplegar un entorno nuevo o actualizar uno existente sin perder el gateway de entrada de Lumi.
- [content.md](content.md): árbol de contenido, cuentas, roles y accesos, con los comandos de RDS Data API. Se lee después del primer despliegue, y cada vez que hace falta agregar una clase o dar acceso a una persona.
- [troubleshooting.md](troubleshooting.md): logs, síntomas, mensajes y limitaciones conocidas. Se lee al diagnosticar un error en la web, en la API o en Lumi.
