# Desarrollo

Ruta para el primer día en el repositorio: levantar el entorno local, recorrer el código, ejecutar las pruebas y conocer las convenciones. Las páginas se leen en este orden.

1. [setup.md](setup.md): requisitos, instalación, cuentas de prueba, servicios locales y diferencias con AWS. Se lee primero, para tener el editor y Lumi corriendo en la máquina local.
2. [repository.md](repository.md): carpetas y paquetes, con su propósito, sus puntos de entrada y cuándo tocarlos. Se lee para ubicar dónde va un cambio.
3. [testing.md](testing.md): pruebas unitarias, de integración, funcionales, end-to-end y de CDK, con sus comandos. Se lee para verificar un cambio.
4. [conventions.md](conventions.md): idioma, TypeScript, ESLint, commits, secretos y diagramas. Se lee para preparar un cambio que respete el repositorio.

Para entender qué hace cada pieza, ver [overview.md](../overview.md) y [architecture/README.md](../architecture/README.md).

Siguiente: [Entorno local](setup.md)
